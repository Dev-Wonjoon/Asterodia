# Asterodia 아이콘

제공된 SVG의 모양·색상·배경을 유지한 아이콘 변환본입니다.

- `asterodia_icon.svg`: 투명 배경의 흰색 심볼 원본
- `asterodia_icon_dark.svg`: `#09090B` 배경의 흰색 심볼 원본
- `asterodia-dark.ico`: Windows 앱 아이콘용 다크 배경 버전
- `asterodia-transparent.ico`: 어두운 배경 위에서 사용하는 투명 버전
- `png/dark/`, `png/transparent/`: 각 버전의 PNG
- `preview.png`: 배경 및 작은 크기 비교 미리보기

PNG 크기: 16, 24, 32, 48, 64, 128, 256, 512, 1024px.
각 ICO에는 16, 24, 32, 48, 64, 128, 256px 이미지가 포함됩니다.

Windows 기본 앱 아이콘에는 `asterodia-dark.ico`를 권장합니다.
투명 버전의 심볼은 흰색이므로 밝은 배경에서는 보이지 않을 수 있습니다.
원본의 선이 얇아 16·24px에서는 세부 선이 흐리게 보일 수 있습니다.
이 묶음은 선 굵기를 임의로 바꾸지 않은 원본 변환본입니다.

앱·홈페이지의 기존 아이콘 교체와 배포는 수행하지 않았습니다.
